# Комп'ютерний практикум з дисципліни «Основи аналізу алгоритмів»

## Варіант 11 — множина точок у двовимірній декартовій площині (KD-Tree)

Програма реалізує консольний інтерфейс для роботи з іменованими множинами
двовимірних точок. Для зберігання точок використовується структура даних
KD-Tree.

Програма підтримує створення декількох незалежних множин, додавання точок,
перевірку входження точки, виведення внутрішньої структури KD-дерева та
отримання всіх точок множини.

## Підтримувані команди

### CREATE
Створює нову множину.

```text
CREATE set_name;
```
### INSERT
Додає точку (x, y) до вказаної множини.

```text
INSERT set_name (x, y);
```

### PRINT_TREE
Виводить внутрішню структуру KD-дерева.

```text
PRINT_TREE set_name;
```

### CONTAINS
Перевіряє, чи належить точка множині.

```text
CONTAINS set_name (x, y);
```

### SEARCH
Виводить усі точки заданої множини. 

```text
SEARCH set_name;
```
## Формат команд
Команди завершуються символом ;.
Ключові слова команд нечутливі до регістру:
- CREATE cities;
- create cities2;
- CrEaTe cities3;

Назви множин є чутливими до регістру.
Наприклад:
- CREATE Cities;
- CREATE cities;

створюють дві різні множини.

#### Команди можуть містити довільні пробільні символи та займати декілька рядків.
Наприклад:
```text
INSERT cities
(
    10,
    20
);
```
Ідентифікатори множин повинні відповідати формату:
```text
[a-zA-Z][a-zA-Z0-9_]*
```
## Представлення KD-дерева
Кожен вузол дерева містить двовимірну точку (x, y) та посилання на ліве і праве піддерева.
Координата, що використовується для порівняння точок, залежить від глибини
вузла:
```text
depth = 0 -> X
depth = 1 -> Y
depth = 2 -> X
depth = 3 -> Y
...
```

Поточна координата визначається як:
```text
depth % 2
```
При вставці точки:
- на рівнях X точки з меншою координатою x переходять у ліве піддерево;
- на рівнях Y точки з меншою координатою y переходять у ліве піддерево;
- інші точки переходять у праве піддерево;
- однакові точки повторно до множини не додаються.

## Структура програми
Програма складається з декількох основних компонентів.

1. Parser
Виконує лексичний та синтаксичний аналіз введених команд.

Вхідний текст перетворюється на токени, після чого перевіряється структура
команди.

2. Command
Зберігає результат розбору однієї команди:
- тип команди;
- ім'я множини;
- координати точки;
- інформацію про коректність команди;
- повідомлення про помилку.

3. SetManager
Керує створеними множинами.

4. KDTree
Реалізує:
- вставку точки;
- пошук точки;
- обхід усіх точок;
- виведення структури дерева;
- звільнення динамічно виділеної пам'яті.

5. Обробка помилок
Програма перевіряє, зокрема:
- невідому команду;
- відсутність ;;
- неправильне ім'я множини;
- неправильний формат координат;
- відсутність (, ), ,;
- зайвий текст у команді;
- повторне створення множини;
- звернення до неіснуючої множини.

## Requirements

- C++17 compatible compiler
- CMake 3.16+
- Boost

Програма використовує

```cpp
boost::multiprecision::cpp_int
```

## Build
### Windows
Проєкт можна скомпілювати за допомогою Visual Studio / MSVC та CMake.

За необхідності встановіть CMake.
Boost можна встановити за допомогою vcpkg.

```powershell
git clone https://github.com/microsoft/vcpkg
cd vcpkg
.\bootstrap-vcpkg.bat
.\vcpkg install boost-multiprecision:x64-windows
```
Потім налаштуйте проект:

```powershell
cmake -S . -B build ^
  -DCMAKE_TOOLCHAIN_FILE=C:/path/to/vcpkg/scripts/buildsystems/vcpkg.cmake
```

Збірка:

```powershell
cmake --build build --config Release
```

Запуск:

```powershell
.\build\Release\kdtree.exe
```

Якщо Boost вже встановлено і CMake його бачить:

```powershell
cmake -S . -B build
cmake --build build --config Release
```

### Linux (Ubuntu / Debian)

Встановлення залежності:

```bash
sudo apt update
sudo apt install build-essential cmake libboost-all-dev
```

Збірка:
```bash
cmake -S . -B build
cmake --build build
```

Запуск:
```bash
./build/kdtree
```

### macOS
Встановіть залежності за допомогою Homebrew:

```bash
brew install cmake boost
```

Збірка:
```bash
cmake -S . -B build
cmake --build build
```

Запуск:
```bash
./build/kdtree
```
